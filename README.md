# Sistema de reservas Software FJ

Programa de consola en Python para administrar clientes, servicios y reservas.

## Funciones

- Registrar clientes y validar datos básicos.
- Calcular costos de salas, alquiler de equipos y asesorías.
- Crear, confirmar y cancelar reservas.
- Validar disponibilidad y duración de servicios.
- Guardar eventos y errores en un archivo de registro.

## Archivos principales

- `main.py`: inicia el programa y presenta ejemplos de uso.
- `modelos.py`: contiene clientes, servicios, reservas y el gestor.
- `excepciones.py`: contiene las excepciones propias del programa.

## Requisitos

- Python 3.11 o superior.

## Ejecución

Desde esta carpeta, ejecutar:

```text
python main.py
```
